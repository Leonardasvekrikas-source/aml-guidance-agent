# CI dependency set: everything the test suite imports, minus the ML stack.
#
# torch, sentence-transformers and transformers are ~2.5GB and are loaded
# lazily inside functions, never at import time. Excluding them takes CI from
# several minutes to well under one, and nothing in the suite touches them —
# the tests that involve a model stub it out, because asserting on model
# behaviour in a unit test measures the model, not the code.
# Pinned. A portfolio repo that installs differently next month is not
# reproducible, and every number in the README depends on reproducibility.
