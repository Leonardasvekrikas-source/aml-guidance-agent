Generated by `make eval-ablation`. One variable changes between runs: the embedding model. Chunk boundaries are computed with a fixed reference tokenizer precisely so that they do not move when the model does — otherwise this would compare model-A-with-A's-chunking against model-B-with-B's-chunking, which is two variables and no conclusion.

## Reading this

**BM25 is the control.** It does not use embeddings, so it must be identical across runs. If it moves, the experiment leaked and nothing else in the table can be trusted.

**The ceiling is the number that matters.** The candidate sweep showed the reranker already uses 100% of the headroom it is given, so the only way to improve the final answer is to put more gold passages into the candidate pool. A ceiling that moves is a real gain; a ceiling that does not is a reshuffle.
